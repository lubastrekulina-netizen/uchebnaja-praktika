# Сумма отрицательных элементов массива на C++

Решение практической задачи по обработке одномерных массивов на языке программирования C++.

## Условие задачи
Дан одномерный массив A размерности N. Найти сумму отрицательных элементов, расположенных между максимальным и минимальным элементами массива (сами экстремумы в расчет не включаются).

## Особенности реализации
* **Динамический размер:** Использование `std::vector` позволяет задавать размер массива N во время выполнения программы.
* **Эффективность:** Поиск минимального и максимального значений происходит за один проход по массиву (линейная сложность O(N)).
* **Универсальность:** Программа корректно работает независимо от того, какой элемент (минимум или максимум) расположен в массиве раньше.

## Требования для запуска
Для компиляции и запуска программы вам понадобятся:
* Компилятор с поддержкой стандарта C++11 или выше (GCC, Clang, MSVC)
* Терминал или среда разработки (IDE), например, Visual Studio, CLion или VS Code

## Инструкция по компиляции и запуску

Вы можете скомпилировать код через терминал с помощью GCC:

```bash
g++ main.cpp -o program
./program
```

## Пример работы программы

**Входные данные:**
```text
Размерность N: 6
Элементы: 5 -3 10 -2 -5 1
```

**Разбор алгоритма:**
1. Максимум = `10` (индекс 2)
2. Минимум = `-5` (индекс 4)
3. Элементы между ними: только `-2` (индекс 3)

**Вывод программы:**
```text
Индекс минимального элемента: 4 (значение: -5)
Индекс максимального элемента: 2 (значение: 10)
Сумма отрицательных элементов между ними: -2
```
