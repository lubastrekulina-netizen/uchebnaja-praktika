# uchebnaja-praktika
Zadanie1
Как работает этот код:
* Динамический массив: Вместо статичных массивов используется std::vector, что позволяет задавать размер \(N\) прямо во время работы программы.
* Один проход для поиска: Индексы максимума и минимума находятся одновременно за один цикл.
* Автоматические границы: Код использует std::min и std::max, чтобы определить, какой элемент встретился раньше, поэтому программа корректно работает независимо от того, где именно в массиве расположены минимум и максимум.
* Строгий диапазон: Цикл подсчета начинается с индекса start + 1 и идет строго до end, исключая сами экстремумы из итоговой суммы.

**Вывод программы:**
```text
Индекс минимального элемента: 4 (значение: -5)
Индекс максимального элемента: 2 (значение: 10)
Сумма отрицательных элементов между ними: -2
```
Zadanie2
Что этот код демонстрирует:
1. Наследование: Класс ElectricCar наследует поля brand, speed и метод showBaseInfo() от класса Vehicle.
2. Переопределение методов (Полиморфизм): Метод startEngine() объявлен в базовом классе как virtual и переопределен в производном с помощью override. В секции main (пункт 3) видно, что при вызове метода через указатель базового класса отрабатывает логика электромобиля, а не обычного авто.
3.Уникальные методы потомка: Метод chargeBattery() создан исключительно внутри ElectricCar и показывает расширение функционала базового класса.
